Política de privacidad

Sistradent · Última actualización: 10 de octubre de 2026

1. Qué es Sistradent

Sistradent es una aplicación de uso privado, operada por su propietario, que se conecta a la API de Gmail para leer la bandeja de entrada de una cuenta de Gmail determinada y enviar correos electrónicos de forma automática desde esa misma cuenta.

2. Datos a los que accede

Con la autorización expresa del propietario de la cuenta, la aplicación puede acceder a:

  • Los mensajes de la bandeja de Gmail (lectura), incluyendo remitente, asunto, cuerpo y adjuntos.
  • La función de envío de correos desde la cuenta autorizada.
  • La modificación de etiquetas y del estado de lectura de los mensajes.

3. Cómo se usan los datos

Los datos de Gmail se usan únicamente para el funcionamiento interno de la aplicación: detectar correos nuevos, enviar notificaciones y responder mensajes. No se utilizan con fines publicitarios ni para entrenar modelos de inteligencia artificial.

4. Compartición de datos

Sistradent no vende, alquila ni comparte los datos de Gmail con terceros.

5. Almacenamiento y seguridad

Las credenciales de acceso (identificador de cliente, secreto y token de actualización) se guardan como variables de entorno protegidas y nunca se publican. El contenido de los correos no se almacena de forma permanente salvo lo estrictamente necesario para el funcionamiento de la aplicación.

6. Uso de la información de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustarán a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

7. Revocar el acceso

El propietario puede revocar el acceso de la aplicación en cualquier momento desde myaccount.google.com/permissions.

8. Contacto

Para consultas sobre esta política, escribe a través del perfil de GitHub del propietario: github.com/stephgl07.
